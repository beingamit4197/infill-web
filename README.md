# Infill Web

Landing page for the [Infill](https://github.com/beingamit4197/infill) Chrome extension — form mapping and smart dummy data injection for modern developers.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Firebase Hosting

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Firebase Hosting

```bash
npm run deploy
```
